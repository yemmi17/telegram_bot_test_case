# Инструкция по настройке

## Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

## Шаг 2: Создание Telegram-бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

## Шаг 3: Готово!

Бот готов к работе! Google Sheets не требуется - бот работает без него.

Если в будущем захотите использовать Google Sheets для хранения прогнозов, см. [SETUP_GOOGLE.md](SETUP_GOOGLE.md)

## Шаг 4: Настройка переменных окружения

1. Создайте файл `.env` в корне проекта
2. Добавьте токен Telegram-бота:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   ```
   
   **Готово!** Бот будет работать без Google Sheets.
   
   (Опционально) Если хотите использовать Google Sheets, см. [SETUP_GOOGLE.md](SETUP_GOOGLE.md)

## Шаг 5: Инициализация данных (опционально)

Если у вас есть исторические данные до 01.11.2021, создайте файл `historical_data.csv` со следующей структурой:

```csv
date,usd_rate
2020-01-01,61.9057
2020-01-02,61.9057
...
```

Если файла нет, бот автоматически начнет собирать данные с Центробанка.

## Шаг 6: Запуск бота

```bash
python bot.py
```

## Тестирование компонентов

Перед запуском бота можно протестировать отдельные компоненты:

```bash
python test_components.py
```

## Устранение проблем

### Ошибка получения данных с Центробанка
- Проверьте интернет-соединение
- Библиотека `pycbrf` может иметь ограничения по частоте запросов
- Попробуйте запустить команду `/update` в боте позже

### Модель не обучается
- Убедитесь, что есть достаточно исторических данных (минимум 30 записей)
- Попробуйте использовать команду `/update` для обновления данных
