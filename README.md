# Telegram-бот для прогнозирования курса USD/RUB

Декларативный Telegram-бот для прогнозирования курса доллара США к российскому рублю на основе исторических данных и математических моделей.

## Возможности

- 📊 Получение данных о курсе валют с сайта Центробанка через библиотеку `pycbrf`
- 🤖 Прогнозирование курса USD/RUB на ближайшую неделю с использованием модели ARIMA
- 📈 Интеграция с Google Sheets для хранения и отображения прогнозов
- 🔄 Автоматическое обновление данных и пересчет прогнозов

## Установка

Подробная инструкция по настройке доступна в файле [SETUP.md](SETUP.md)

Краткая инструкция:

1. Клонируйте репозиторий или скачайте файлы проекта

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` с токеном Telegram-бота:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   ```
   
   **Готово!** Бот будет работать без Google Sheets.

4. (Опционально) Если хотите использовать Google Sheets:
   - См. инструкцию в [SETUP_GOOGLE.md](SETUP_GOOGLE.md)
   - Добавьте в `.env` название таблицы или URL

## Использование

1. Запустите бота:
```bash
python bot.py
```

2. Найдите вашего бота в Telegram и отправьте команду `/start`

3. Доступные команды:
   - `/start` - Начать работу с ботом
   - `/forecast` - Получить прогноз курса USD/RUB на ближайшую неделю
   - `/update` - Обновить данные с Центробанка и пересчитать прогноз
   - `/help` - Показать справку

## Структура проекта

- `bot.py` - Основной файл Telegram-бота
- `data_fetcher.py` - Модуль для получения данных с Центробанка
- `predictor.py` - Модуль для прогнозирования курса валют
- `google_sheets.py` - Модуль для работы с Google Sheets (опционально)
- `test_components.py` - Скрипт для тестирования компонентов
- `init_data.py` - Скрипт для инициализации исторических данных
- `requirements.txt` - Зависимости проекта
- `.env` - Переменные окружения (создать самостоятельно)
- `SETUP.md` - Подробная инструкция по настройке
- `QUICK_START.md` - Быстрый старт
- `SETUP_GOOGLE.md` - Инструкция по настройке Google Sheets (опционально)
- `historical_data.csv` - Файл с историческими данными (создается автоматически)

## Особенности реализации

- **Модель прогнозирования**: Используется модель ARIMA (AutoRegressive Integrated Moving Average) для временных рядов
- **Данные**: Исторические данные до 01.11.2021 дополняются актуальными данными с сайта Центробанка
- **Google Sheets**: Опциональная интеграция с Google Sheets для хранения прогнозов (не требуется для работы бота)
- **Доверительные интервалы**: Прогнозы включают верхнюю и нижнюю границы с уровнем доверия 95%

## Требования

- Python 3.8+
- Активное интернет-соединение
- Токен Telegram-бота (получить у @BotFather)

## Примечания

- При первом запуске бот автоматически загрузит данные с Центробанка
- Данные сохраняются в файл `historical_data.csv` для ускорения последующих запусков
- Прогнозы обновляются при каждом запуске бота и при использовании команды `/update`
