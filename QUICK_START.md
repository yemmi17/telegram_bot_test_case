# Быстрый старт

## Базовая настройка (без Google Sheets)

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Создайте файл `.env`:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   ```

3. Запустите бота:
   ```bash
   python bot.py
   ```

**Готово!** Бот работает и выдает прогнозы. Google Sheets не требуется.

## (Опционально) С Google Sheets

Если хотите сохранять прогнозы в Google Sheets, см. подробную инструкцию в [SETUP_GOOGLE.md](SETUP_GOOGLE.md)

**Важно:** Google Sheets не требуется для работы бота. Все функции доступны и без него.  

## Команды бота

- `/start` - Начать работу
- `/forecast` - Получить прогноз на неделю
- `/update` - Обновить данные и пересчитать прогноз
- `/help` - Справка
