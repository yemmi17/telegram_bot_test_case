# Упрощенная настройка Google Sheets (без Service Account)

## Вариант 1: Использование OAuth токена (рекомендуется)

### Шаг 1: Создание OAuth 2.0 Client ID

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект или выберите существующий
3. Включите **Google Sheets API**:
   - Перейдите в "APIs & Services" → "Library"
   - Найдите "Google Sheets API" и нажмите "Enable"
4. Создайте OAuth 2.0 Client ID:
   - Перейдите в "APIs & Services" → "Credentials"
   - Нажмите "Create Credentials" → "OAuth client ID"
   - Если появится запрос, настройте OAuth consent screen:
     - Выберите "External" (для личного использования)
     - Заполните обязательные поля (App name, User support email)
     - Добавьте свой email в "Test users"
     - Сохраните и продолжите
   - Выберите тип приложения: **"Desktop app"**
   - Назовите клиент (например, "Bot Sheets")
   - Нажмите "Create"
5. Скачайте JSON файл:
   - Нажмите на созданный OAuth client ID
   - Нажмите "Download JSON"
   - Сохраните файл как `credentials.json` в корне проекта

### Шаг 2: Получение токена

Запустите скрипт для получения токена:

```bash
python get_google_token.py
```

Скрипт:
1. Откроет браузер для авторизации
2. Попросит разрешить доступ к Google Sheets
3. Сохранит токен в файл `token.pickle`

**Важно:** Токен будет сохранен и использоваться автоматически. Обновление токена происходит автоматически при истечении.

### Шаг 3: Настройка таблицы

**Вариант A: По названию таблицы**

1. Создайте таблицу Google Sheets (или используйте существующую)
2. Убедитесь, что вы имеете к ней доступ
3. В `.env` укажите:
   ```
   GOOGLE_SPREADSHEET_NAME=Название вашей таблицы
   ```

**Вариант B: По URL таблицы (проще)**

1. Создайте таблицу Google Sheets
2. Скопируйте URL таблицы из адресной строки браузера
3. В `.env` укажите:
   ```
   GOOGLE_SPREADSHEET_URL=https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID
   ```

### Шаг 4: Готово!

Теперь бот будет автоматически использовать Google Sheets для хранения прогнозов.

## Вариант 2: Публичная таблица (только чтение)

Если вам нужен только просмотр данных без записи:

1. Создайте таблицу Google Sheets
2. Нажмите "Настройки доступа" → "Изменить на: Все, у кого есть ссылка"
3. Скопируйте URL таблицы
4. Используйте URL в настройках бота

**Примечание:** Для записи данных все равно потребуется авторизация через OAuth.

## Устранение проблем

### Ошибка "Токен не найден"
- Запустите `python get_google_token.py` для получения токена

### Ошибка "Токен истек"
- Токен должен обновляться автоматически
- Если проблема сохраняется, запустите `get_google_token.py` снова

### Ошибка "Spreadsheet not found"
- Проверьте название таблицы или URL
- Убедитесь, что вы имеете доступ к таблице
- Попробуйте использовать URL вместо названия

### Бот работает без Google Sheets
- Это нормально, бот может работать и без Google Sheets
- Прогнозы будут генерироваться, но не сохраняться в таблицу
- Для сохранения в таблицу настройте OAuth токен
